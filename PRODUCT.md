# Tic Tac Toe

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Play a quick round of tic-tac-toe against a friend on the same device or against a browser-based opponent. Players can practice against a casual opponent, test perfect play, or train a bot whose preferences carry across rounds.

## Capabilities and constraints

X opens each round. Local play shares one board and AI opponents play O. Scores, sound preferences and adaptive learning stay on the device. Players can undo a move, start again, tune the adaptive bot and reset saved results. The interface supports a keyboard, mouse or touch.

The project uses React, TypeScript and Vite. A static production build must run on Cloudflare Pages without an API key or application server.
